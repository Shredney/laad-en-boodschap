# Laad & Boodschap — gratis GitHub Pages

Dit is de complete publiceerbare app, inclusief iconen, licenties en broncode.
Geen account voor bezoekers, API-sleutel of eigen server nodig. Nieuwe zoekopdrachten gebruiken publieke internetdiensten.

Eenmalig publiceren via je eigen privé-GitHub-account:

1. Maak een leeg **public** repository, bijvoorbeeld laad-en-boodschap. Gratis GitHub Pages vereist bij GitHub Free een openbaar repository.
2. Pak het hosting-ZIP uit en upload de bestanden uit deze map naar de root van dat repository. `index.html` moet direct in de root staan, niet in een extra submap. Publiceer geen projectarchief, screenshots of volledige werkmap.
3. Kies bij **Settings → Pages → Deploy from a branch** de branch **main** en **/(root)**. GitHub toont daarna je eigen HTTPS-link.

Open die link op je telefoon. Via het browsermenu kun je de app aan het startscherm toevoegen. Je pc hoeft niet aan te blijven. Publicatie via de site-instellingen kan enkele minuten duren.

Werkt: Europese routes, OSM-laadpunten en winkels, routevensters inclusief de laatste uren, ketenfilters, winkeldetails, kopiëren, PWA-appschil. Dekking hangt af van brongegevens.
Deze statische versie gebruikt voor Nederland de ingebedde NDW-momentopname. Live-NDW en serververversing zijn bewust uitgeschakeld; er wordt geen actuele bezetting verzonnen.
De appschil kan na een eerder bezoek beschikbaar blijven, maar nieuwe kaart-/route-/locatiegegevens vereisen internet. Rechtstreeks openen via file:// op Android vervangt HTTPS-hosting niet betrouwbaar.

Officiële uitleg: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
